# موقع رسالة من المعلمة عوالي منصور

## النشر عبر GitHub Pages
1. أنشئي مستودعًا جديدًا في GitHub.
2. ارفعي الملفين `index.html` و`README.md` إلى جذر المستودع (لا ترفعي ملف ZIP نفسه باعتباره ملفات الموقع).
3. من Settings ثم Pages اختاري Deploy from a branch.
4. اختاري Branch: main والمجلد: /(root)، ثم Save.
5. انتظري اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## تنبيه تقني
هذه نسخة HTML مستقلة للمعاينة. توزيع الرسائل فيها محلي داخل المتصفح، ولا تستخدم قاعدة بيانات مشتركة بين الأجهزة. لاستخدام توزيع مركزي ثابت للرسائل بين جميع الطالبات، يلزم مشروع التطبيق المرتبط بـ Supabase وإعداداته، وهي غير موجودة ضمن هذه النسخة.
